# DutyHuddle

Compare daily roulettes and Wondrous Tails with your party, and get advice on your journal.

## Install

1. In game, open `/xlsettings` → **Experimental**.
2. Under **Custom Plugin Repositories**, paste
   `https://raw.githubusercontent.com/FortyFive00/DutyHuddle/main/repo.json`, tick **Enabled**, then **Save**.
3. Open `/xlplugins`, search for **DutyHuddle** and install it.
4. Type `/dutyhuddle`.

Party members see each other's data when they also use DutyHuddle and turn on **Sharing → Share with my party**.
